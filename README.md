# 🌳 Real Wood Furnitures

### Premium Furniture Showroom Website — Gujrat, Pakistan

A modern, elegant, and responsive website designed for **Real Wood Furnitures**, a furniture showroom located in Gujrat, Punjab, Pakistan.

The website showcases furniture collections, showroom photography, business information, and provides customers with direct WhatsApp communication and Google Maps navigation.

---

## 🌐 Project Overview

Real Wood Furnitures is a premium business website focused on creating a strong online presence for a local furniture showroom.

The goal is to help customers:
- Explore furniture collections.
- View showroom photographs.
- Discover available furniture products.
- Contact the showroom directly through WhatsApp.
- Find the physical showroom using Google Maps.
- Learn about the business and its services.

## ✨ Key Features

- Premium and modern UI/UX design.
- Fully responsive layout (mobile, tablet, desktop).
- Three-page website architecture.
- Elegant furniture photography gallery.
- Furniture collection and product showcase.
- WhatsApp integration with product-specific inquiry messages.
- Click-to-call functionality.
- Google Maps integration.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to Project Folder

```bash
cd real-wood-furnitures
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```
